# RZER Performance website

Gloss-black 3D website for Rzer, a Singapore car tuning workshop. It has a liquid-to-car hero intro, scroll scenes around the car and a parts configurator. Everything ships as one HTML file with no libraries.

```bash
npm run build   # writes dist/index.html
npm run dev     # rebuilds on change
```

Open `dist/index.html` in a browser. Add `#build` to the address to go straight to the configurator.

See `CLAUDE.md` for the architecture, performance rules and how to add parts.
